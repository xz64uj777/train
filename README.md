# Valley Division

A browser train simulator. Run the New England valley from Briar Yard to Tidewater: throttle, dynamic brake, air, signals, and a career of four jobs.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints. On a phone, drag the view to look around and pinch to zoom. The **Map** button shows the route and the grade profile. The grade next to the speed is the hill under the locomotive right now: plus is uphill, minus is downhill.

## Controls

- Power / Less: throttle notches 1–8, then idle, then dynamic brake
- Air / Release: train air brake
- W / S, Space, E on a keyboard
- Horn, look left and right, headlight, emergency

## Jobs

1. First trick hostling — yard work
2. River Local — the valley towns and the meet at East Ferry
3. Summit Stone — the grade, after the mountain qualification
4. Evening passenger extra — after the passenger qualification

Career progress stays in the browser.
